# 鲸鱼娘造型图 · 生图提示词

游戏里每套造型现在都有一个现画的头饰，能直接用。想换成真正的造型图，按下面的提示词生成，放进 `src/assets/outfits/`，再到 `src/outfits.ts` 的 `IMAGES` 里登记：

```ts
import diverImg from './assets/outfits/diver.jpg'
export const IMAGES: Partial<Record<OutfitId, string>> = { diver: diverImg }
```

登记后游戏、相册、分享卡都会用这张图，不再叠加头饰。改完记得 `npm run build`。

## 出图要求

- 用 `src/assets/whale-girl-head.jpg`（或原始手办图）做角色参考图，保证是同一个角色
- 正方形，512×512 左右就够，jpg，单张最好不超过 40KB（会打包进 client.js）
- 构图和 whale-girl-head.jpg 一致：头部到肩膀的特写，脸在画面正中略偏下，纯浅灰背景
- 头饰别贴边，会被裁成圆形，四个角的内容看不到

## 通用前缀（每条都带上）

> Q版3D手办风格，同一个角色：蓝色渐变长卷发、头顶一根呆毛、两侧是鲸鱼鳍形状的耳朵、蓝色大眼睛、浅浅的微笑，PVC 质感，柔和棚拍光，纯浅灰色背景，头部到肩膀特写，正面，居中，正方形构图
